# CAD Design Projects

## Overview
This repository contains a collection of my personal CAD design and modelling projects, developed while exploring different engineering design software and techniques.

## Software
- OpenSCAD — Script-based parametric 3D modelling
- FreeCAD — 3D CAD modelling and mechanical design
- LibreCAD — 2D technical drafting
- AutoCAD Mechanical — Mechanical drafting and engineering drawings

## Project Categories
- 3D CAD and Parametric Design
- 2D Mechanical Drafting
- Engineering Drawings

## About
These are personal side projects, separate from my professional research and industry work. Individual project folders will contain design files, screenshots and project descriptions where available.
