# OpenSCAD Projects

## Overview

This folder showcases my personal projects and experiments in parametric 3D modelling and computer-aided design (CAD) using OpenSCAD.

OpenSCAD is a script-based 3D CAD modelling tool that enables the creation of customisable geometric models through programming.

These projects reflect my interest in exploring code-driven design techniques, computational geometry, and parametric modelling for engineering applications.

## Areas of Exploration

- Script-based 3D CAD modelling
- Parametric and customisable geometric designs
- Constructive Solid Geometry (CSG)
- Geometric transformations and Boolean operations
- Algorithmic design using variables, modules, and functions
- 3D model visualisation and export

## Software and Tools

- **OpenSCAD** — Script-based 3D CAD modelling
- **SCAD scripting language** — Parametric geometry generation
- **STL** — Export format for 3D models, where available

## Project Files

Individual project folders may include:

- `.scad` source code files
- `.stl` exported 3D models
- Screenshots and rendered images
- Design parameters and modelling notes
- Project descriptions and documentation

## Purpose

The purpose of this collection is to document my exploration of parametric CAD modelling and code-based design workflows through independent projects.

These projects are personal learning and design activities, separate from my professional research and industry work.
